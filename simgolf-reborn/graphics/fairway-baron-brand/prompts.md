# Fairway Baron — brand and start-screen concepts

The user chose **Fairway Baron** as the new game name on 2026-09-12. The ten visual directions below await selection. Created with the built-in image-generation tool, one generation per direction. Each PNG combines a logo, splash artwork, and proposed start menu. These are concept illustrations, not implemented game screens or final standalone logo assets.

After selection: refine the chosen logo, produce standalone assets and responsive background crops, and implement an accessible live menu integrated with the existing account flow. Existing domains, storage keys and technical identifiers are not renamed by this concept package.

Review: [Comparison gallery](index.html).
