# Opening music

`pristine-fairway.mp3` was supplied by the project owner for the Fairway Baron splash screen and pre-game interface. Original uploaded filename: `1-pristine_fairway.mp3`. The file is copied without audio edits (stereo, 44.1 kHz, approximately 3:01).

The menu player loops at 28% volume, remembers a local mute preference, retries playback on user interaction when autoplay is blocked, and pauses while the page is hidden. It is stopped and rewound when leaving the opening flow for gameplay. No claim about authorship or third-party licensing is inferred from the supplied file.
