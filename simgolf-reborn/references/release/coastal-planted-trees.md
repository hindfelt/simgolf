# Coastal planted trees

The existing Tree tool now renders tapered layered conifer crowns on non-desert coastal courses, matching the coastal scenery direction. Desert courses retain smaller scrub vegetation, including desert/coast combinations. Other courses retain broadleaf trees. Environment changes invalidate the visual cache even when the edit revision is unchanged. Tree identity, save data, placement, removal and simulation collision rules are unchanged; this is a regional presentation change, not a new selectable species catalog or exact canopy-physics claim.

Chrome verification covers tapered crown geometry, ray selection, desert appearance changes and removing all instances. The production build passed, and a standalone grove was rendered and visually reviewed. Upper branches were shortened after visual review to fit the crown. Regional architecture, independently selectable species and the full approved coastal composition remain open.
