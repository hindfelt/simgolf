# Course categories and skill caps

[Official hints, archived by Backswing](https://jztemple.tripod.com/backswing/docs/ohints.htm), FAQ dated 31 January 2002, lists Municipal 0–5 holes/60% skill maximum; Golf Course 6–9/80%; Country Club 10–17/100%; Championship 18/no maximum. The page identifies these as copied from the official site; fan additions are separately described. Retrieved in search-index text during the design-note investigation.

Implementation counts complete tee/green pairs, including closed holes. Allocations beyond the course cap are blocked; imported profiles remain intact and new rounds use capped snapshots. The source does not explain imported-profile handling or removing holes, so these preservation choices remain provisional. Existing active saved rounds are preserved. Skills beyond the current ten-point profile budget remain a separate career-progression requirement.

Tests cover all 18 construction boundaries, incomplete holes, closed holes, saved profile preservation, effective skill snapshots and actual browser allocation controls.
