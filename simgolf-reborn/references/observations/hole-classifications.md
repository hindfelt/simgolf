# Hole classification evidence

Supplied golf.exe strings contain all eight labels and tutorial descriptions linking each to Length, Accuracy and Imagination. This confirms names and qualitative combinations without executing the binary.

[Backswing tips](https://jztemple.tripod.com/backswing/tips.htm/cheats.htm) gives a 0.50 cutoff for non-Classic types. It is explicitly unofficial and does not resolve equality or the three-skill interval below Classic. [Sid Meier notes](https://jztemple.tripod.com/backswing/sgid.htm) describe Classic as all three ratings at least 1.00. The report leaves unresolved results unclassified rather than inventing a ninth original category.

These labels are estimates derived from current prototype shot behavior. Original sample requirements, exact boundaries and recognition/reward behavior remain unverified. Tests exercise all eight skill combinations through cohort scoring, missing comparisons and ambiguous thresholds; the phone report verifies the resulting heading.
